# HTTP API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `sovrag serve` exposes `POST /query` and `GET /healthz` over HTTP with the principal bound by the server in `static` or `gateway` mode, returning the same `Answer` the CLI prints and writing the same audit line.

**Architecture:** A pure-ASGI binding layer in `src/sovrag/api/gate.py` puts the principal on `scope["state"]` before routing: `StaticBinding` for one configured principal, `GatewayGate` for a verified bearer plus an `X-Sovrag-Principal` header resolved against the principals file. `src/sovrag/api/app.py` builds a FastAPI app whose one handler reads the principal from request state, calls `sovrag.generate.answer.answer` with a server-generated request id, and returns `asdict(Answer)`. `sovrag serve` builds the app the way `serve-mcp` does and refuses to start on bad configuration.

**Tech Stack:** Python 3.14, FastAPI and uvicorn (already dependencies), Starlette request state, `hmac.compare_digest`, pydantic v2 models, httpx2 `ASGITransport` in tests. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-01-http-api-design.md`

## Global Constraints

- `API_IDENTITY` is required, with no default and no fallback between `static` and `gateway`; `build_app` raises `ValueError` naming the problem for an unset or unknown mode, a missing or unknown `PRINCIPAL` in static mode, or an empty `API_SHARED_SECRET` in gateway mode, and `sovrag serve` turns that into exit code 2.
- The principal comes from `scope["state"]["principal"]`, set by the binding layer, and from nowhere else; the request body cannot name it (`extra="forbid"`, so a `principal` field is 422).
- In gateway mode a failed bearer or an unknown `X-Sovrag-Principal` is 401 `{"detail": "unauthorised"}`, never a downgrade to `LEAST_PRIVILEGED`; `GET /healthz` is exempt from the gate.
- Bearer comparison uses `hmac.compare_digest`; the secret is never logged or echoed.
- One audit line per request, written by `answer()`; the API writes no event of its own and a 401 writes nothing.
- `k` outside 1..`MAX_K` is clamped, not rejected; `question` is stripped and must be 1 to 2000 characters.
- Response 200 is `dataclasses.asdict(Answer)` unchanged, with `request_id` also in the `X-Request-ID` header; `GenerationError` is 502 `{"detail": "generation failed: <message>", "request_id": ...}`.
- Tests first; keep test-only helpers out of `src/`; `ruff check --no-cache`, `ruff format --check`, `mypy src` and `pytest` pass at every commit.
- Never write copy implying real protected data was used (ADR 0003). No private planning, schedule or session references in files or commits.
- Commit messages end with the two trailer lines main uses: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and `Claude-Session: <the session URL given in the dispatch>`.

## Review Focus

Inputs the spec implies but did not spell out, each pinned by a test in the task that owns the code:

1. A question that is only whitespace must be 422, not an empty-string call to `answer()` (Task 2).
2. An `Authorization` header with the right token but the wrong scheme (`Basic`, or no scheme) must be 401; a header value with surrounding whitespace around the principal id must still resolve (Task 1).
3. A client-supplied `X-Request-ID` must not be trusted: the server generates its own and returns that one (Task 2).
4. A malformed JSON body, or a `k` that is not an integer, must be 422 and must not reach `answer()` (Task 2).
5. `GET /healthz` in gateway mode must answer without a bearer, and `POST /healthz` must not become an unauthenticated path to anything (Task 1).

"""Binding the principal for the HTTP API, before routing (ADR 0009, ADR 0015).

Two pure-ASGI middlewares put the principal on `scope["state"]["principal"]`, where the one
handler reads it. StaticBinding uses the principal configured at startup. GatewayGate trusts
an authenticating gateway: the request must carry the shared secret as a bearer and a known
principal id in X-Sovrag-Principal; anything else is 401, never a downgrade. GET /healthz
passes unbound so a load balancer can probe without the secret.
"""

from __future__ import annotations

import hmac
from collections.abc import Awaitable, Callable, Mapping, MutableMapping
from enum import StrEnum
from typing import Any

from starlette.responses import JSONResponse

from sovrag.auth import Principal

Scope = MutableMapping[str, Any]
Receive = Callable[[], Awaitable[MutableMapping[str, Any]]]
Send = Callable[[MutableMapping[str, Any]], Awaitable[None]]
ASGIApp = Callable[[Scope, Receive, Send], Awaitable[None]]

PRINCIPAL_HEADER = "x-sovrag-principal"
HEALTH_PATH = "/healthz"
UNAUTHORISED = {"detail": "unauthorised"}


class Identity(StrEnum):
    static = "static"
    gateway = "gateway"


def _bind(scope: Scope, principal: Principal) -> None:
    scope.setdefault("state", {})["principal"] = principal


def _headers(scope: Scope) -> dict[str, str]:
    return {k.decode("latin-1").lower(): v.decode("latin-1") for k, v in scope.get("headers", [])}


class StaticBinding:
    """Every HTTP request runs as the one principal configured at startup."""

    def __init__(self, app: ASGIApp, principal: Principal) -> None:
        self._app = app
        self._principal = principal

    async def __call__(self, scope: Scope, receive: Receive, send: Send) -> None:
        if scope["type"] == "http":
            _bind(scope, self._principal)
        await self._app(scope, receive, send)


class GatewayGate:
    """Bearer plus X-Sovrag-Principal, resolved against the principals loaded at startup."""

    def __init__(self, app: ASGIApp, *, secret: str, principals: Mapping[str, Principal]) -> None:
        self._app = app
        self._secret = secret
        self._principals = principals

    async def __call__(self, scope: Scope, receive: Receive, send: Send) -> None:
        if scope["type"] != "http":
            await self._app(scope, receive, send)
            return
        if scope["method"] == "GET" and scope["path"] == HEALTH_PATH:
            await self._app(scope, receive, send)
            return
        principal = self._authorise(_headers(scope))
        if principal is None:
            await JSONResponse(UNAUTHORISED, status_code=401)(scope, receive, send)
            return
        _bind(scope, principal)
        await self._app(scope, receive, send)

    def _authorise(self, headers: Mapping[str, str]) -> Principal | None:
        scheme, _, token = headers.get("authorization", "").strip().partition(" ")
        if scheme.lower() != "bearer" or not hmac.compare_digest(token.strip(), self._secret):
            return None
        return self._principals.get(headers.get(PRINCIPAL_HEADER, "").strip())
```

```

`build_app` returns a FastAPI app whose ASGI stack is `StaticBinding(fastapi_app, principal)` or `GatewayGate(fastapi_app, secret=..., principals=...)`. Because the middleware must be the outermost ASGI callable, `build_app` returns the FastAPI object with the binding attached via `app.add_middleware`-free wrapping: set `app = FastAPI(...)` then return a FastAPI whose `__call__` is the wrapped one. The simplest correct way: build the FastAPI app, then assign `app.middleware_stack = None` is not needed; instead wrap at the top with Starlette's `Middleware`-free approach: `fastapi_app.add_middleware(StaticBinding, principal=principal)` works because Starlette's `add_middleware` instantiates `cls(app, **options)` and places it outermost. Use that: `StaticBinding(app, principal)` becomes `add_middleware(StaticBinding, principal=principal)` and `GatewayGate` becomes `add_middleware(GatewayGate, secret=..., principals=...)`. The gate classes already take `app` first, which is what Starlette passes.

The app records its mode on `app.state.identity` and, in static mode, `app.state.principal_id`, for `/healthz` and for `serve`'s start-up line.

```python
"""The HTTP API: POST /query and GET /healthz, with the principal bound before routing.

The handler reads the principal from request state, which only the binding layer in gate.py
writes. It generates the request id, so the audit line answer() writes can be joined to the
access log, and returns the Answer unchanged: the same object `sovrag ask --json` prints.
"""

from __future__ import annotations

import uuid
from dataclasses import asdict
from pathlib import Path

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse
from pydantic import BaseModel, ConfigDict, Field, field_validator

from sovrag.api.gate import HEALTH_PATH, GatewayGate, Identity, StaticBinding
from sovrag.auth import load_principals, resolve_principal
from sovrag.config import Settings
from sovrag.generate import MAX_K, GenerationError
from sovrag.generate.answer import answer
from sovrag.retrieve import Mode

# Module-level name so tests can substitute the generator without touching the route.
generate_answer = answer

QUESTION_MAX_CHARS = 2000


class QueryRequest(BaseModel):
    model_config = ConfigDict(extra="forbid")

    question: str = Field(min_length=1, max_length=QUESTION_MAX_CHARS)
    mode: Mode = Mode.hybrid
    k: int = 5

    @field_validator("question", mode="before")
    @classmethod
    def _strip(cls, value: object) -> object:
        return value.strip() if isinstance(value, str) else value


def _identity(settings: Settings) -> Identity:
    try:
        return Identity(settings.api_identity)
    except ValueError:
        raise ValueError(
            f"API_IDENTITY must be 'static' or 'gateway', got {settings.api_identity!r}"
        ) from None


def build_app(settings: Settings) -> FastAPI:
    """Build the app. Raises ValueError for any configuration that could bind the wrong
    principal, so `sovrag serve` refuses to start rather than run degraded."""
    identity = _identity(settings)
    app = FastAPI(title="sovrag", docs_url=None, redoc_url=None, openapi_url=None)
    app.state.identity = identity
    app.state.principal_id = None
    path = Path(settings.principals_path)

    if identity is Identity.static:
        if not settings.principal:
            raise ValueError("PRINCIPAL is required in static mode")
        try:
            principal = resolve_principal(settings.principal, path)
        except KeyError:
            raise ValueError(f"PRINCIPAL {settings.principal!r} is not in {path}") from None
        app.state.principal_id = principal.id
        app.add_middleware(StaticBinding, principal=principal)
    else:
        if not settings.api_shared_secret:
            raise ValueError("API_SHARED_SECRET is required in gateway mode")
        app.add_middleware(
            GatewayGate, secret=settings.api_shared_secret, principals=load_principals(path)
        )

    @app.get(HEALTH_PATH)
    async def healthz() -> dict[str, object]:
        return {"status": "ok", "identity": identity.value, "principal": app.state.principal_id}

    @app.post("/query")
    async def query(request: Request, body: QueryRequest) -> JSONResponse:
        principal = request.state.principal
        request_id = uuid.uuid4().hex
        k = max(1, min(body.k, MAX_K))
        try:
            result = generate_answer(
                body.question, principal=principal, mode=body.mode, k=k, request_id=request_id
            )
        except GenerationError as exc:
            return JSONResponse(
                {"detail": str(exc), "request_id": request_id},
                status_code=502,
                headers={"X-Request-ID": request_id},
            )
        return JSONResponse(asdict(result), headers={"X-Request-ID": request_id})

    return app
```

Notes for the implementer: `generate_answer` is synchronous and blocks the event loop for the duration of a model call; FastAPI runs `def` handlers in a thread pool but `async def` handlers inline. Declare the `query` handler as a plain `def` (not `async def`) so the blocking call runs in the thread pool; the tests work either way. `GenerationError` messages already start with "generation failed:" (see `src/sovrag/generate/llm.py`), so `str(exc)` matches the spec's body. `add_middleware` wraps outermost, so the gate runs before routing and before FastAPI's body validation; a 401 therefore never parses the body.

- [ ] **Step 1: Write ADR 0015**

Follow `docs/adr/0013-entitlement-predicate.md`'s shape: title, `Status: accepted (2026-10-01)`, Context, Decision, Consequences.

- Context: the README promised an HTTP entry point; the CLI and MCP paths exist; ADR 0009 fixed the rule that the server binds the principal from configuration or a verified transport. Over HTTP there is no plugin to vouch for the user.
- Decision: two modes chosen by `API_IDENTITY` with no default. `static` for one tenant. `gateway` trusts an authenticating reverse proxy or portal: bearer equal to `API_SHARED_SECRET` (constant time) and `X-Sovrag-Principal` naming an entry in the principals file, resolved in a pure-ASGI gate before routing; anything else is 401 and never a downgrade. `GET /healthz` is exempt. One endpoint, `POST /query`, returning the CLI's `Answer`; no `/search` because agents have the MCP tools and retrieval-only callers have the CLI. The body cannot name a principal (`extra="forbid"`). One audit line per request, written by `answer()`, keyed by a server-generated request id echoed in `X-Request-ID`.
- The gateway's obligations and the pattern's limits, in the words of ADR 0009: strip inbound `X-Sovrag-Principal`, reach the port only from the gateway, treat the secret as an administrator credential; whoever holds it can name any principal; per-caller tokens or OAuth can replace the mode later without changing the endpoint.
- Consequences: the Compose `app` service runs static mode by default so `docker compose up -d` still serves; the Dockerfile's default command is now real; the eval harness's leak answer check could be pointed at the API later; `sovrag serve` leaves the "not implemented" list.
