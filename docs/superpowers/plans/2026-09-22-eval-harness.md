# Evaluation Harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `sovrag eval` with three suites: retrieval and leak, deterministic and gated in CI against a committed full-precision index; generation, judged locally by a different model family and committed with its model labels.

**Architecture:** Pure metric functions and golden-file loaders under `src/sovrag/eval/`, a fixture module that serialises the live index to JSONL plus raw float32 and loads it back exactly, three runners that call the same `search` and `answer` functions users call, one result envelope carrying model, quantization and backend labels, and a `sovrag eval` command group. Hand-written golden data lives under `eval/golden/`; generated data under `eval/fixture/`; committed runs under `eval/results/`.

**Tech Stack:** Python 3.14, psycopg 3 with pgvector, typer, pytest, the standard `array` and `hashlib` modules. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-22-eval-harness-design.md`

## Global Constraints

- Golden items reference chunks as `(doc_id, ordinal)`, never by the `chunks.id` serial.
- The fixture is the full corpus at full precision: little-endian float32, row-major, no half precision, no subset.
- Golden items are written by reading chunk text document by document, never from retrieval output; each item's `notes` names what was read.
- The leak suite's forbidden set is an independent Python statement of the visibility rule, tested to agree with the SQL predicate for every named principal; it never reuses `sovrag.retrieve.filters.PREDICATE`.
- The generation run refuses to start when the judge model equals the generator model.
- Every result file records `embed_model`, `llm_model`, `judge_model`, `engine`, `engine_backend` and the git commit.
- Thresholds in `eval/thresholds.json` may be raised by a pull request and never lowered.
- Tests first; keep test-only helpers out of `src/`; `ruff check`, `ruff format --check`, `mypy src` and `pytest` pass at every commit.
- Never write copy implying real protected data was used (ADR 0003). Do not mention any private planning outside the repo.
- Commit messages end with the two trailer lines main already uses: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and `Claude-Session: <the session URL given in the dispatch>`.
- Postgres tests use the `db` fixture from `tests/conftest.py` (needs `docker compose up -d postgres`); they skip when Postgres is unreachable, so run them with Postgres up.

```python
"""Ranking metrics. Pure functions over any hashable key; the runners use (doc_id, ordinal)."""

from __future__ import annotations

from collections.abc import Collection, Sequence


def hit_at_k[T](ranked: Sequence[T], gold: Collection[T], k: int) -> float:
    """1.0 when any gold key appears in the first k ranked keys."""
    return 1.0 if any(key in gold for key in ranked[:k]) else 0.0


def recall_at_k[T](ranked: Sequence[T], gold: Collection[T], k: int) -> float:
    """Fraction of gold keys that appear in the first k ranked keys."""
    if not gold:
        return 0.0
    found = sum(1 for key in set(ranked[:k]) if key in gold)
    return found / len(gold)


def mrr[T](ranked: Sequence[T], gold: Collection[T]) -> float:
    """Reciprocal of the 1-based rank of the first gold key; 0.0 when none is ranked."""
    for rank, key in enumerate(ranked, start=1):
        if key in gold:
            return 1.0 / rank
    return 0.0


def mean(values: Sequence[float]) -> float:
    return sum(values) / len(values) if values else 0.0
```

```python
"""Golden sets: hand-written questions with the chunks that answer them.

Chunks are named by (doc_id, ordinal), never by the chunks.id serial, because ids change on
every ingest and ordinals are fixed by the deterministic chunker. Files load strictly so a
typo in a gold reference fails the suite instead of silently scoring zero.
"""

from __future__ import annotations

import json
from collections.abc import Collection, Iterator
from dataclasses import dataclass
from pathlib import Path
from typing import Any

GOLDEN_DIR = Path("eval/golden")


@dataclass(frozen=True)
class GoldChunk:
    doc_id: str
    ordinal: int


@dataclass(frozen=True)
class RetrievalItem:
    id: str
    question: str
    gold: tuple[GoldChunk, ...]
    reference_answer: str
    notes: str


@dataclass(frozen=True)
class UnanswerableItem:
    id: str
    question: str
    notes: str


@dataclass(frozen=True)
class LeakItem:
    id: str
    question: str
    gold: tuple[GoldChunk, ...]
    notes: str


def _rows(path: Path) -> Iterator[tuple[int, dict[str, Any]]]:
    seen: set[str] = set()
    for lineno, line in enumerate(path.read_text(encoding="utf-8").splitlines(), start=1):
        if not line.strip():
            continue
        row = json.loads(line)
        item_id = row.get("id")
        if not isinstance(item_id, str) or not item_id:
            raise ValueError(f"{path}:{lineno}: missing id")
        if item_id in seen:
            raise ValueError(f"{path}:{lineno}: duplicate id {item_id}")
        seen.add(item_id)
        yield lineno, row


def _field(path: Path, lineno: int, row: dict[str, Any], name: str) -> Any:
    if name not in row:
        raise ValueError(f"{path}:{lineno}: {row['id']}: missing {name}")
    return row[name]


def _gold(
    path: Path, lineno: int, row: dict[str, Any], known_doc_ids: Collection[str] | None
) -> tuple[GoldChunk, ...]:
    raw = _field(path, lineno, row, "gold")
    if not raw:
        raise ValueError(f"{path}:{lineno}: {row['id']}: gold is empty")
    gold = tuple(GoldChunk(doc_id=str(g["doc_id"]), ordinal=int(g["ordinal"])) for g in raw)
    if known_doc_ids is not None:
        for g in gold:
            if g.doc_id not in known_doc_ids:
                raise ValueError(f"{path}:{lineno}: {row['id']}: unknown doc_id {g.doc_id}")
    return gold


def load_retrieval(
    path: Path, *, known_doc_ids: Collection[str] | None = None
) -> list[RetrievalItem]:
    return [
        RetrievalItem(
            id=row["id"],
            question=str(_field(path, n, row, "question")),
            gold=_gold(path, n, row, known_doc_ids),
            reference_answer=str(_field(path, n, row, "reference_answer")),
            notes=str(_field(path, n, row, "notes")),
        )
        for n, row in _rows(path)
    ]


def load_unanswerable(path: Path) -> list[UnanswerableItem]:
    return [
        UnanswerableItem(
            id=row["id"],
            question=str(_field(path, n, row, "question")),
            notes=str(_field(path, n, row, "notes")),
        )
        for n, row in _rows(path)
    ]


def load_leak(path: Path, *, known_doc_ids: Collection[str] | None = None) -> list[LeakItem]:
    return [
        LeakItem(
            id=row["id"],
            question=str(_field(path, n, row, "question")),
            gold=_gold(path, n, row, known_doc_ids),
            notes=str(_field(path, n, row, "notes")),
        )
        for n, row in _rows(path)
    ]
```

```python
"""The committed index: documents, chunks and their embeddings, plus embedded golden questions.

Built from the live index after ingest, loaded into any index (CI's service Postgres) so the
retrieval and leak suites run without a model. Embeddings are raw little-endian float32,
which is exactly what pgvector stores, so the loaded index equals the built one. Every file
is sha256-checked on load; the fixture is generated, never hand-edited.
"""

from __future__ import annotations

import hashlib
import json
import sys
from array import array
from collections.abc import Callable, Sequence
from datetime import UTC, datetime
from itertools import groupby
from pathlib import Path
from typing import Any

import psycopg

from sovrag.corpus.chunk import Chunk
from sovrag.corpus.manifest import DocumentMeta
from sovrag.index.store import replace_chunks, upsert_document

FIXTURE_DIR = Path("eval/fixture")
DOC_COLUMNS = (
    "id",
    "title",
    "department",
    "classification",
    "doc_type",
    "fiscal_year",
    "source_url",

)

def _write_f32(path: Path, vectors: Sequence[Sequence[float]], dim: int) -> None:
    arr = array("f")
    for v in vectors:
        if len(v) != dim:
            raise ValueError(f"embedding of length {len(v)} != dim {dim}")
        arr.extend(float(x) for x in v)
    if sys.byteorder != "little":
        arr.byteswap()
    path.write_bytes(arr.tobytes())


def _read_f32(path: Path, dim: int) -> list[list[float]]:
    arr = array("f")
    arr.frombytes(path.read_bytes())
    if sys.byteorder != "little":
        arr.byteswap()
    if len(arr) % dim:
        raise ValueError(f"{path.name}: {len(arr)} floats is not a multiple of dim {dim}")
    return [list(arr[i : i + dim]) for i in range(0, len(arr), dim)]


def _write_jsonl(path: Path, rows: Sequence[dict[str, Any]]) -> None:
    path.write_text("".join(json.dumps(r, ensure_ascii=False) + "\n" for r in rows), "utf-8")


def _read_jsonl(path: Path) -> list[dict[str, Any]]:
    return [json.loads(line) for line in path.read_text("utf-8").splitlines() if line.strip()]


def _sha256(path: Path) -> str:
    return hashlib.sha256(path.read_bytes()).hexdigest()


def _manifest(fixture_dir: Path) -> dict[str, Any]:
    manifest: dict[str, Any] = json.loads((fixture_dir / "manifest.json").read_text("utf-8"))
    for name, expected in manifest["sha256"].items():
        actual = _sha256(fixture_dir / name)
        if actual != expected:
            raise ValueError(f"{name}: sha256 {actual} != manifest {expected}; rebuild the fixture")
    return manifest


def build_fixture(
    conn: psycopg.Connection,
    out_dir: Path,
    questions: Sequence[tuple[str, str]],
    embed: Callable[[Sequence[str]], list[list[float]]],
    *,
    embed_model: str,
    dim: int,
) -> dict[str, int]:
    out_dir.mkdir(parents=True, exist_ok=True)
    doc_rows = conn.execute(
        f"select {', '.join(DOC_COLUMNS)} from documents order by id"
    ).fetchall()
    documents = [dict(zip(DOC_COLUMNS, row, strict=True)) for row in doc_rows]
    chunk_rows = conn.execute(
        "select doc_id, ordinal, heading_path, text, embedding from chunks order by doc_id, ordinal"
    ).fetchall()
    chunks = [
        {"doc_id": r[0], "ordinal": r[1], "heading_path": r[2] or "", "text": r[3]}
        for r in chunk_rows
    ]
    embeddings = [[float(x) for x in r[4]] for r in chunk_rows]
    question_rows = [{"id": qid, "question": text} for qid, text in questions]
    question_vectors = embed([text for _, text in questions]) if questions else []

    _write_jsonl(out_dir / "documents.jsonl", documents)
    _write_jsonl(out_dir / "chunks.jsonl", chunks)
    _write_f32(out_dir / "chunks.f32", embeddings, dim)
    _write_jsonl(out_dir / "questions.jsonl", question_rows)
    _write_f32(out_dir / "questions.f32", question_vectors, dim)
    manifest = {
        "embed_model": embed_model,
        "dim": dim,
        "documents": len(documents),
        "chunks": len(chunks),
        "questions": len(question_rows),
        "built_at": datetime.now(UTC).isoformat(),
        "sha256": {name: _sha256(out_dir / name) for name in FILES},
    }
    (out_dir / "manifest.json").write_text(json.dumps(manifest, indent=2) + "\n", "utf-8")
    return {"documents": len(documents), "chunks": len(chunks), "questions": len(question_rows)}


def read_documents(fixture_dir: Path) -> list[dict[str, str | None]]:
    _manifest(fixture_dir)
    return _read_jsonl(fixture_dir / "documents.jsonl")


def read_chunks(fixture_dir: Path) -> list[dict[str, object]]:
    _manifest(fixture_dir)
    return _read_jsonl(fixture_dir / "chunks.jsonl")


def load_fixture(conn: psycopg.Connection, fixture_dir: Path) -> dict[str, int]:
    manifest = _manifest(fixture_dir)
    documents = _read_jsonl(fixture_dir / "documents.jsonl")
    chunks = _read_jsonl(fixture_dir / "chunks.jsonl")
    embeddings = _read_f32(fixture_dir / "chunks.f32", int(manifest["dim"]))
    if len(embeddings) != len(chunks):
        raise ValueError(f"{len(chunks)} chunks but {len(embeddings)} embeddings")
    for doc in documents:
        upsert_document(conn, DocumentMeta(pages=(), **doc))
    rows = list(zip(chunks, embeddings, strict=True))
    for doc_id, group in groupby(rows, key=lambda r: str(r[0]["doc_id"])):
        pairs = list(group)
        replace_chunks(
            conn,
            doc_id,
            [Chunk(int(c["ordinal"]), str(c["heading_path"]), str(c["text"])) for c, _ in pairs],
            [e for _, e in pairs],
        )
    return {"documents": len(documents), "chunks": len(chunks)}


def load_question_embeddings(fixture_dir: Path) -> dict[str, list[float]]:
    manifest = _manifest(fixture_dir)
    questions = _read_jsonl(fixture_dir / "questions.jsonl")
    vectors = _read_f32(fixture_dir / "questions.f32", int(manifest["dim"]))
    if len(vectors) != len(questions):
        raise ValueError(f"{len(questions)} questions but {len(vectors)} embeddings")
    return {str(q["id"]): v for q, v in zip(questions, vectors, strict=True)}
```

Note for the implementer: `DocumentMeta(pages=(), **doc)` works because `documents.jsonl` rows carry exactly the other eight fields; `fiscal_year` may be `None`. `register_vector` on the connection makes `embedding` come back as a numpy array; `float(x)` per element converts it.

```python
"""Retrieval suite: hit@5, recall@10 and MRR per mode, from precomputed question vectors.

Calls the same search functions users call, with the same HNSW settings, so the numbers
describe the real query path. The principal is the caller's choice; the CLI passes auditor,
who sees every document, so gold chunks are never filtered out.
"""

from __future__ import annotations

from collections.abc import Mapping, Sequence

import psycopg

from sovrag.auth import Principal
from sovrag.eval.golden import RetrievalItem
from sovrag.eval.metrics import hit_at_k, mean, mrr, recall_at_k
from sovrag.eval.report import SuiteResult
from sovrag.retrieve import Mode, search

MODES = (Mode.vector, Mode.keyword, Mode.hybrid)
K = 10
_NAMES = ("hit@5", "recall@10", "mrr", "doc_hit@5")


def run_retrieval(
    conn: psycopg.Connection,
    items: Sequence[RetrievalItem],
    embeddings: Mapping[str, Sequence[float]],
    *,
    principal: Principal,
    k: int = K,
) -> SuiteResult:
    per_mode: dict[Mode, dict[str, list[float]]] = {
        mode: {name: [] for name in _NAMES} for mode in MODES
    }
    rows: list[dict[str, object]] = []
    for item in items:
        if item.id not in embeddings:
            raise KeyError(f"no question embedding for {item.id}; rebuild the fixture")
        vector = embeddings[item.id]
        gold = {(g.doc_id, g.ordinal) for g in item.gold}
        gold_docs = {g.doc_id for g in item.gold}
        for mode in MODES:
            hits = search(
                conn,
                item.question,
                mode=mode,
                k=k,
                embed_query=lambda _q: vector,
                principal=principal,
            )
            ranked = [(h.doc_id, h.ordinal) for h in hits]
            scores = {
                "hit@5": hit_at_k(ranked, gold, 5),
                "recall@10": recall_at_k(ranked, gold, 10),
                "mrr": mrr(ranked, gold),
                "doc_hit@5": hit_at_k([d for d, _ in ranked], gold_docs, 5),
            }
            for name, value in scores.items():
                per_mode[mode][name].append(value)
            rows.append(
                {"id": item.id, "mode": mode.value, "ranked": [list(r) for r in ranked], **scores}
            )
    metrics = {
        f"{mode.value}.{name}": mean(values)
        for mode, scores_by_name in per_mode.items()
        for name, values in scores_by_name.items()
    }
    return SuiteResult(metrics=metrics, rows=rows)
```

The `embed_query=lambda _q: vector` closes over the loop variable deliberately: it is called before the next iteration. If ruff flags B023, bind it with a default: `lambda _q, v=vector: v`.

```python
"""Leak suite: a principal never retrieves a chunk from a document they may not see.

The forbidden set comes from this module's own statement of the visibility rule, not from
the SQL predicate in sovrag.retrieve.filters. An oracle that reused the predicate would
inherit its bugs; a test asserts the two agree for every named principal instead.
"""

from __future__ import annotations

from collections.abc import Callable, Mapping, Sequence

import psycopg

from sovrag.auth import GC_WIDE, Clearance, Principal
from sovrag.eval.golden import LeakItem
from sovrag.eval.report import SuiteResult
from sovrag.generate.answer import Answer
from sovrag.retrieve import Mode, search

MODES = (Mode.vector, Mode.keyword, Mode.hybrid)
K = 10


def visible(principal: Principal, classification: str, department: str) -> bool:
    """The visibility rule (ADR 0013), stated independently of the SQL predicate."""
    if Clearance(classification).rank > principal.clearance.rank:
        return False
    return (
        classification == Clearance.UNCLASSIFIED.value
        or department == GC_WIDE
        or department in principal.departments
    )


def forbidden_doc_ids(conn: psycopg.Connection, principal: Principal) -> frozenset[str]:
    rows = conn.execute("select id, classification, department from documents").fetchall()
    return frozenset(doc_id for doc_id, cls, dept in rows if not visible(principal, cls, dept))


def run_leak(
    conn: psycopg.Connection,
    items: Sequence[LeakItem],
    embeddings: Mapping[str, Sequence[float]],
    principals: Mapping[str, Principal],
    *,
    control: Principal,
    k: int = K,
) -> SuiteResult:
    forbidden = {name: forbidden_doc_ids(conn, p) for name, p in principals.items()}
    rows: list[dict[str, object]] = []
    leaks = 0
    checks = 0
    control_hits = 0
    for item in items:
        if item.id not in embeddings:
            raise KeyError(f"no question embedding for {item.id}; rebuild the fixture")
        vector = embeddings[item.id]
        for name, principal in principals.items():
            for mode in MODES:
                checks += 1
                hits = search(
                    conn,
                    item.question,
                    mode=mode,
                    k=k,
                    embed_query=lambda _q, v=vector: v,
                    principal=principal,
                )
                for h in hits:
                    if h.doc_id in forbidden[name]:
                        leaks += 1
                        rows.append(
                            {
                                "id": item.id,
                                "principal": name,
                                "mode": mode.value,
                                "doc_id": h.doc_id,
                                "ordinal": h.ordinal,
                            }
                        )
        gold = {(g.doc_id, g.ordinal) for g in item.gold}
        control_ranked = search(
            conn,
            item.question,
            mode=Mode.hybrid,
            k=k,
            embed_query=lambda _q, v=vector: v,
            principal=control,
        )
        hit = any((h.doc_id, h.ordinal) in gold for h in control_ranked)
        control_hits += int(hit)
        rows.append({"id": item.id, "control_hit": hit})
    metrics = {
        "leaks": float(leaks),
        "checks": float(checks),
        "positive_control": float(control_hits),
    }
    return SuiteResult(metrics=metrics, rows=rows)


def run_leak_answers(
    items: Sequence[LeakItem],
    principals: Mapping[str, Principal],
    answer_fn: Callable[[str, Principal], Answer],
) -> SuiteResult:
    """Local only: how often the generator refuses a leak question as each principal.
    Reported, not gated: visible material may legitimately overlap the question."""
    rows: list[dict[str, object]] = []
    metrics: dict[str, float] = {}
    for name, principal in principals.items():
        asked = refused = 0
        for item in items:
            result = answer_fn(item.question, principal)
            asked += 1
            refused += int(result.refused)
            rows.append({"id": item.id, "principal": name, "refused": result.refused})
        metrics[f"{name}.asked"] = float(asked)
        metrics[f"{name}.refused"] = float(refused)
    return SuiteResult(metrics=metrics, rows=rows)
```

```python
"""Generation suite: faithfulness and correctness judged by a different model family.

The judge sees the question, the chunks the answer cited, the reference answer and the
answer, and returns one small JSON object. A judge from the generator's own family would
share its blind spots, so the run refuses to start when the two model ids are equal.
"""

from __future__ import annotations

import json
import random
import re
import time
from collections.abc import Callable, Mapping, Sequence
from dataclasses import dataclass
from typing import Any

import psycopg

from sovrag.eval.golden import RetrievalItem, UnanswerableItem
from sovrag.eval.metrics import mean
from sovrag.eval.report import SuiteResult
from sovrag.generate.answer import Answer

CORRECT_VALUES = ("yes", "partial", "no")
HUMAN_CHECK_SAMPLE = 10

JUDGE_SYSTEM = (
    "You grade an answer produced from numbered sources. Reply with one JSON object and nothing "
    'else: {"faithful": true or false, "unsupported_claims": [strings], "correct": "yes" or '
    '"partial" or "no"}. faithful is false when any claim in the answer is not supported by the '
    "sources; list each such claim in unsupported_claims. correct compares the answer to the "
    "reference: yes when it states the same facts, partial when it states some, no otherwise."
)

_FENCE = re.compile(r"^```(?:json)?\s*|\s*```$", re.MULTILINE)


@dataclass(frozen=True)
class Verdict:
    faithful: bool
    unsupported_claims: tuple[str, ...]
    correct: str


def judge_messages(
    question: str, answer_text: str, sources: Sequence[str], reference: str
) -> list[dict[str, str]]:
    numbered = "\n\n".join(f"[{i}] {text}" for i, text in enumerate(sources, start=1))
    user = (
        f"Sources:\n\n{numbered}\n\nQuestion: {question}\n\nReference answer: {reference}\n\n"
        f"Answer to grade: {answer_text}"
    )
    return [{"role": "system", "content": JUDGE_SYSTEM}, {"role": "user", "content": user}]


def parse_verdict(text: str) -> Verdict:
    cleaned = _FENCE.sub("", text.strip()).strip()
    try:
        data = json.loads(cleaned)
    except json.JSONDecodeError as exc:
        raise ValueError(f"judge reply is not JSON: {text[:80]!r}") from exc
    if not isinstance(data, dict) or not isinstance(data.get("faithful"), bool):
        raise ValueError(f"judge reply lacks a boolean faithful: {cleaned[:80]!r}")
    correct = data.get("correct")
    if correct not in CORRECT_VALUES:
        raise ValueError(f"judge reply has correct={correct!r}, expected one of {CORRECT_VALUES}")
    claims = data.get("unsupported_claims") or []
    return Verdict(
        faithful=bool(data["faithful"]),
        unsupported_claims=tuple(str(c) for c in claims),
        correct=str(correct),
    )


def chunk_texts(conn: psycopg.Connection, chunk_ids: Sequence[int]) -> dict[int, str]:
    if not chunk_ids:
        return {}
    rows = conn.execute("select id, text from chunks where id = any(%s)", (list(chunk_ids),))
    return {int(cid): str(text) for cid, text in rows.fetchall()}


def _timed(fn: Callable[[], Answer]) -> tuple[Answer, float]:
    start = time.perf_counter()
    result = fn()
    return result, time.perf_counter() - start


def run_generation(
    items: Sequence[RetrievalItem],
    unanswerable: Sequence[UnanswerableItem],
    *,
    answer_fn: Callable[[str], Answer],
    judge_fn: Callable[[Sequence[dict[str, str]]], str],
    chunk_text_fn: Callable[[Sequence[int]], Mapping[int, str]],
    generator_model: str,
    judge_model: str,
    seed: int = 0,
) -> SuiteResult:
    if generator_model == judge_model:
        raise ValueError(f"judge model must differ from the generator, both are {judge_model!r}")
    rows: list[dict[str, Any]] = []
    latencies: list[float] = []
    verdicts: list[Verdict] = []
    parse_failures = 0
    false_refusals = 0
    for item in items:
        result, latency = _timed(lambda: answer_fn(item.question))
        latencies.append(latency)
        row: dict[str, Any] = {
            "id": item.id,
            "kind": "answerable",
            "refused": result.refused,
            "answer": result.text,
            "citations": [c.chunk_id for c in result.citations],
            "verdict": None,
            "latency_s": round(latency, 3),
        }
        if result.refused:
            false_refusals += 1
        else:
            texts = chunk_text_fn([c.chunk_id for c in result.citations])
            sources = [texts.get(c.chunk_id, "") for c in result.citations]
            try:
                verdict = parse_verdict(
                    judge_fn(
                        judge_messages(item.question, result.text, sources, item.reference_answer)
                    )
                )
            except ValueError:
                parse_failures += 1
            else:
                verdicts.append(verdict)
                row["verdict"] = {
                    "faithful": verdict.faithful,
                    "unsupported_claims": list(verdict.unsupported_claims),
                    "correct": verdict.correct,
                }
        rows.append(row)
    unanswerable_refusals = 0
    for u in unanswerable:
        result, latency = _timed(lambda: answer_fn(u.question))
        latencies.append(latency)
        unanswerable_refusals += int(result.refused)
        rows.append(
            {
                "id": u.id,
                "kind": "unanswerable",
                "refused": result.refused,
                "answer": result.text,
                "latency_s": round(latency, 3),
            }
        )
    judged = [r for r in rows if r["kind"] == "answerable" and r["verdict"] is not None]
    for r in random.Random(seed).sample(judged, min(HUMAN_CHECK_SAMPLE, len(judged))):
        r["human_check"] = None
    n_judged = len(verdicts)
    metrics = {
        "faithful_rate": mean([1.0 if v.faithful else 0.0 for v in verdicts]),
        "correct_yes": mean([1.0 if v.correct == "yes" else 0.0 for v in verdicts]),
        "correct_partial": mean([1.0 if v.correct == "partial" else 0.0 for v in verdicts]),
        "correct_no": mean([1.0 if v.correct == "no" else 0.0 for v in verdicts]),
        "false_refusal_rate": false_refusals / len(items) if items else 0.0,
        "unanswerable_refusal_rate": (
            unanswerable_refusals / len(unanswerable) if unanswerable else 0.0
        ),
        "judge_parse_failures": float(parse_failures),
        "judged": float(n_judged),
        "mean_latency_s": mean(latencies),
    }
    return SuiteResult(metrics=metrics, rows=rows)


def agreement_rate(rows: Sequence[Mapping[str, Any]]) -> float | None:
    filled = [r for r in rows if r.get("human_check") is not None and r.get("verdict")]
    if not filled:
        return None
    agreed = sum(1 for r in filled if bool(r["human_check"]) == bool(r["verdict"]["faithful"]))
    return agreed / len(filled)
```

`human_check` semantics for the reader who fills it: `true` means "I agree the answer is faithful", `false` means "I judge it unfaithful". Agreement is against the judge's `faithful`.

```python
    try:

    except KeyError as exc:
        raise typer.BadParameter(f"unknown principal: {principal_id}") from exc


def _known_doc_ids(conn: psycopg.Connection) -> set[str]:
    return {str(r[0]) for r in conn.execute("select id from documents").fetchall()}


def _finish(suite: str, settings: Settings, result: SuiteResult, out: Path | None) -> None:
    path = write_report(make_report(suite, settings, result), out or default_path(suite))
    for name, value in result.metrics.items():
        typer.echo(f"{name:32} {value:.3f}")
    typer.echo(f"wrote {path}")


def _gate(misses: list[str]) -> None:
    if misses:
        for miss in misses:
            typer.echo(f"threshold miss: {miss}", err=True)
        raise typer.Exit(code=1)
    typer.echo("thresholds met")


@eval_app.command("build-fixture")
def build_fixture_cmd(golden_dir: GoldenDir = GOLDEN_DIR, out: FixtureDir = FIXTURE_DIR) -> None:
    """Serialise the live index and embed every golden question. Needs the embedding model."""
    settings = get_settings()
    with connect(settings.database_url) as conn:
        known = _known_doc_ids(conn)
        items = load_retrieval(golden_dir / "retrieval.jsonl", known_doc_ids=known)
        unanswerable = load_unanswerable(golden_dir / "unanswerable.jsonl")
        leaks = load_leak(golden_dir / "leak.jsonl", known_doc_ids=known)
        questions = [(i.id, i.question) for i in [*items, *unanswerable, *leaks]]
        embedder = Embedder.from_settings(settings)
        counts = build_fixture(
            conn,
            out,
            questions,
            embedder.embed,
            embed_model=settings.embed_model,
            dim=settings.embed_dim,
        )
    typer.echo(", ".join(f"{k}: {v}" for k, v in counts.items()))

@eval_app.command()
def retrieval(
    golden_dir: GoldenDir = GOLDEN_DIR,
    fixture_dir: FixtureDir = FIXTURE_DIR,
    out: Out = None,
    check: Check = False,
    principal: Annotated[
        str, typer.Option(help="Who searches; must see every document")
    ] = "auditor",
) -> None:
    """hit@5, recall@10 and MRR for every mode, from precomputed question vectors."""
    settings = get_settings()
    who = _bind(principal, settings)
    items = load_retrieval(golden_dir / "retrieval.jsonl")
    embeddings = load_question_embeddings(fixture_dir)

        result = run_retrieval(conn, items, embeddings, principal=who)
    _finish("retrieval", settings, result, out)
    if check:

@eval_app.command()
def leak(
    golden_dir: GoldenDir = GOLDEN_DIR,
    fixture_dir: FixtureDir = FIXTURE_DIR,
    out: Out = None,
    check: Check = False,
    answers: Annotated[
        bool, typer.Option("--answers", help="Also ask the generator; needs a model")
    ] = False,
) -> None:
    """Zero forbidden chunks for every named principal, plus a positive control as auditor."""
    settings = get_settings()
    principals = load_principals(Path(settings.principals_path))
    items = load_leak(golden_dir / "leak.jsonl")
    embeddings = load_question_embeddings(fixture_dir)
    with connect(settings.database_url) as conn:
        result = run_leak(conn, items, embeddings, principals, control=principals["auditor"])
    if answers:
        subset = {name: principals[name] for name in LEAK_ANSWER_PRINCIPALS}
        asked = run_leak_answers(
            items, subset, lambda q, p: answer(q, principal=p, mode=Mode.hybrid, k=5)
        )
        result = SuiteResult({**result.metrics, **asked.metrics}, [*result.rows, *asked.rows])
    _finish("leak", settings, result, out)
    if check:
        floor = load_thresholds(THRESHOLDS_PATH)["leak"]
        misses = check_thresholds(result.metrics, {"positive_control": floor["positive_control"]})
        if result.metrics["leaks"] > 0:
            misses.insert(0, f"leaks: {int(result.metrics['leaks'])} forbidden chunks returned")
        _gate(misses)


@eval_app.command()
def generation(
    golden_dir: GoldenDir = GOLDEN_DIR,
    out: Out = None,
    seed: Annotated[int, typer.Option(help="Seed for the human-check sample")] = 0,
) -> None:
    """Faithfulness and correctness judged by JUDGE_MODEL; refusals on unanswerable questions."""
    settings = get_settings()
    if not settings.judge_model:
        raise typer.BadParameter(
            "set JUDGE_MODEL to a model from a different family than LLM_MODEL"
        )
    auditor = _bind("auditor", settings)
    items = load_retrieval(golden_dir / "retrieval.jsonl")
    unanswerable = load_unanswerable(golden_dir / "unanswerable.jsonl")
    judge = Generator(
        base_url=settings.judge_base_url or settings.llm_base_url,
        model=settings.judge_model,
        api_key=settings.judge_api_key or "not-needed",
        max_retries=settings.llm_max_retries,
        timeout_s=settings.llm_timeout_s,
    )

            )

        raise typer.Exit(code=2) from exc
```

- [ ] **Step 1: Write ADR 0014**

Follow the shape of `docs/adr/0013-entitlement-predicate.md`: title, `Status: accepted (2026-09-22)`, Context, Decision, Consequences. Content:

- Context: the README promises retrieval quality, grounded answers and no leaks; none is provable from unit tests; CI has no model.
- Decision, five parts: (1) the full corpus at full precision is committed as the fixture with precomputed question embeddings, so CI measures the index users query; (2) golden items are written from chunk text, keyed by `(doc_id, ordinal)`, never from retrieval output; (3) the leak oracle is an independent Python statement of the rule, tested to agree with the SQL predicate; (4) the judge is a different model family (Gemma 4 12B) and the run refuses a judge equal to the generator; (5) every result carries model tags, `engine` and `engine_backend`, and thresholds may only rise.
- Consequences: 14 MB of binary in the repo, regenerated by one command; HNSW approximation means thresholds sit below the baseline; the generation suite is local and its numbers are labelled; a full-precision run on vLLM is a settings change plus a new result file, and is not this ADR.
